Basic Questions

1. What operations do you need to do to calculate the required values in your program? List each one and say why.

Addition (+):
I use addition to add the tax to the meal amount. This gives the total cost of the meal with tax.

Multiplication (*):
I use multiplication to calculate the tax and tip amounts. For example, the meal amount is multiplied by 7.5% to calculate the tax.

Division (/):
I use division to convert cents into whole dollars when displaying the values. For example, 5000 cents divided by 100 gives 50 dollars.

Modulo (%):
I use the modulo operator to find the remaining cents after calculating the whole dollars. For example, 5050 % 100 gives 50 cents.

2. When would you use assignment operators?

Assignment operators are used when I want to store a value in a variable or change the value of a variable. The basic assignment operator is =. For example, meal_cents = 5000 assigns the value 5000 to the meal_cents variable. Other assignment operators, such as +=, -=, *=, and /=, can be used to modify an existing value.


Tracing and Explaining the Sample Program

1. Why does apples * price produce a double?

The apples variable is an int and price is a double. When an integer is used in an operation with a double, the integer is automatically converted to a double. Therefore, apples * price produces a double.


2. What information is lost when (int)total is performed?

The decimal portion of total is lost. The cast converts the double to an int, which keeps only the whole-number portion. For example, if total were 6.93, converting it to an int would produce 6.


3. What would happen if ratio were written as:

double ratio = apples / 2;

Both apples and 2 are integers, so integer division would be performed first. 7 / 2 would produce 3 instead of 3.5. The result would then be converted to a double, so ratio would contain 3.00.


4. Which conversions are implicit and which are explicit?

The conversion of apples from int to double in apples * price is an implicit conversion because C performs it automatically.

The conversion in (int)total is an explicit conversion because the programmer specifically uses a cast to convert the double to an int.

The expression (double)apples is also an explicit conversion because the programmer tells C to convert apples to a double.
