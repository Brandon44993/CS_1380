What are the advantages of using a Linux system for C programming?
    Linux provides a powerful command-line environment for C programming. It has tools such as GCC for compiling programs and provides easy access 
    to development utilities. Linux is also widely used for system programming, which makes it a useful environment for learning how C programs 
    interact with the operating system and computer hardware.

Why is it important to specify the C standard when compiling?
    It is important to specify the C standard because different versions of C can support different language features and syntax. 
    Using `-std=c23` tells the compiler to follow the C23 standard when compiling the program. This helps ensure that the code is compiled 
    according to the language version being used and makes the compiler's behavior more predictable.

What does GCC do and why is it important?
    GCC stands for GNU Compiler Collection. It is a compiler that translates C source code into an executable program that the computer can run. 
    GCC is important because it allows programmers to compile, test, and run their C programs from the command line.

What basic compilation commands did you learn?

    I learned that I can compile a C program using GCC with a command such as:
    gcc c23_intro.c -Wall -Wextra -std=c23 -g -o c23_intro
    The -std=c23 option tells GCC to use the C23 standard. The -Wall and -Wextra options enable additional compiler warnings, 
    and -g includes debugging information. The -o option specifies the name of the executable.
    I also learned that I can run the compiled program from the terminal using:
    ./c23_intro
