========================================
BASIC QUESTIONS
===============

1. How do you find shell commands?

I can find shell commands by using commands such as man, help, apropos, and which. The man command provides detailed documentation for many commands. The help command provides information about shell built-in commands. The apropos command searches manual-page descriptions for keywords, and which can show the location of an executable command.

2. What's the difference between find and locate?

The find command searches directories and files directly on the filesystem when I run it. It can search using names, file types, sizes, dates, and other conditions. The locate command searches a database of file paths, so it is usually faster, but its database may not contain the most recently created files. On my system, locate was not installed and Ubuntu suggested installing plocate.

3. What are basic shell commands for file management?

Some basic file-management commands are ls for listing files, cd for changing directories, pwd for showing the current directory, cp for copying files, mv for moving or renaming files, rm for removing files, mkdir for creating directories, and chmod for changing file permissions.

4. What interested you most about shell commands?

What interested me most was how shell commands can quickly search and manage many files without opening them individually. I found find and grep especially useful because I could search my homework directories and locate specific files or text from the terminal.
